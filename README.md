#BNGU计算机视觉考核

本项目包含了所有考核内容（Lab 1 - Lab 3）。

##环境依赖与配置 (Environment Setup)
本项目基于 Python 3.14 开发，核心依赖库为 OpenCV 和 NumPy。
请在终端中执行以下命令一键安装：
`pip install -r requirements.txt`

##文件目录与输出说明

本项目所有的源码、输入素材和输出结果均存放在项目根目录，具体说明如下：

* **源码文件**：`lab1.py`, `lab2.py`, `lab2(plus).py`, `lab3.py`
* **输入素材**：`lab1.png`, `lab2.png` , `lab2(plus).mp4`图像及视频素材。
* **📝 实验结果展示**：**文件名中带有 `out` 的文件（例如 `lab1_out.png`），均为本程序运行后成功生成的实验输出结果文件。
**

* 
* **注**：Lab 3 会调用电脑默认摄像头。运行中如需退出，请在画面窗口中按 `q` 键。
